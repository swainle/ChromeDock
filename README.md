# ChromeDock

ChromeDock 是 Windows 桌面程序。它管理多个浏览器环境，并为每个环境使用独立的用户数据目录。你可以设置代理、语言、时区、系统和浏览器标识。

## 运行要求

- 使用 Windows。
- 将可用的 `chrome.exe` 放在程序目录的 `Chrome-bin` 文件夹中。程序从 `Chrome-bin\chrome.exe` 启动浏览器。
- 从源代码构建时，安装 .NET 10 SDK。

## 从源代码运行

在仓库根目录运行：

```powershell
dotnet run --project ChromeDock/ChromeDock.csproj
```

如需生成 Windows x64 版本，运行：

```powershell
dotnet publish ChromeDock/ChromeDock.csproj -c Release -r win-x64
```

发布后，仍需把 `Chrome-bin\chrome.exe` 放在可执行文件旁的 `Chrome-bin` 文件夹中。

## 使用

1. 启动 ChromeDock。
2. 单击“新建环境”。
3. 填写环境名称。按需设置代理、语言、时区、系统和浏览器标识。
4. 单击“保存”，或单击“保存并启动”。
5. 在环境列表中单击“打开”或“关闭”。

你可以按名称或 ID 搜索环境，并按运行状态筛选环境。单击“修改”可以打开环境操作菜单。该菜单提供编辑、复制和删除操作。编辑启动参数前，请先关闭环境。

如需修改用户数据目录，单击主界面的设置按钮。输入完整路径，然后单击“保存”。修改目录前，请先关闭所有环境。

## 数据位置

程序在可执行文件所在目录保存以下数据：

| 路径 | 内容 |
| --- | --- |
| `Data\sqlite.db` | 环境记录和设置 |
| `UserData\<ID>` | 默认的浏览器用户数据目录 |
| `Logs\<日期>` | 运行日志 |

你可以在设置中更改用户数据根目录。删除环境时，程序保留该环境的用户数据目录和配置副本。程序下次启动时会从保留的数据恢复环境。如需永久清除数据，请先确认目录内容，再自行删除对应的用户数据目录。

## IP 检测

单击环境列表中的 IP 信息可以检查网络地址。你可以在设置中填写 IPinfo API Token。免费接口失败时，程序会使用该 Token。留空并保存可清除 Token。
